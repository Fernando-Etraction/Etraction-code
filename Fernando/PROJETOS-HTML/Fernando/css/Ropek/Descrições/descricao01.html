Sobre a peça Conforto e proteção para acompanhar cada descoberta

O Macacão Bebê Algodão Preto Floresta é uma peça prática e versátil para o enxoval. Confeccionado em 100% algodão, oferece toque macio, conforto e liberdade para o bebê brincar, passear ou descansar. A cor preta com estampa de bichinhos da floresta cria um visual encantador e unissex para diferentes momentos do dia.
